🔄 Convertir KMZ ⇄ Shapefile

Sube un .kmz/.kml para convertirlo a Shapefile, o un .shp (+ .dbf/.prj sueltos, o zipeado) para convertirlo a KMZ. Todo se procesa en tu navegador — no se sube nada a internet.

🛰️ Agregar capa WMS

Conectá una capa remota de un servicio WMS (OGC). Se agrega como una capa más, independiente de tus archivos locales — podés mostrarla, ocultarla o quitarla en cualquier momento. Los valores de ejemplo son un servicio real de IDE Chile.

🧩 Agregar capa WFS

Descargá los elementos (vectores) de un servicio WFS (OGC) y agregalos como una capa local más — quedan disponibles en el buscador, el árbol y los gráficos, igual que un KML o GeoJSON cargado a mano. Solo se descarga lo que ves en el mapa: navegá/alejá el zoom antes de cargar para cubrir otra zona. Se piden hasta 500 elementos por vez; si la capa tiene geometrías muy detalladas, acercá el zoom para reducir el área y evitar una descarga muy pesada.

🌐 Catálogo de servicios

Elegí un servicio WMS/WFS ya conocido en vez de buscar la URL a mano. Al presionar "Usar servicio" se abre el formulario habitual con la URL ya cargada y se buscan sus capas automáticamente — es el mismo flujo de siempre, solo que con la URL puesta. Si preferís, seguís pudiendo ingresar una URL manualmente desde "🛰️ + Capa WMS" / "🧩 + Capa WFS".
